Link a number

hermitator joins the number as a linked device, the way WhatsApp Web does. The phone keeps working as usual.

Scan the QR code

  1. Open WhatsApp on the phone with the number hermitator should use, usually your agent's own number.
  2. Go to Settings, then Linked devices, then Link a device.
  3. Point the phone at this code.

Getting a code from WhatsApp…

Or use the phone number

If you cannot scan, enter the number and type the code into WhatsApp under Link with phone number instead.
